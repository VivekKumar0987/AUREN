```text
I built AUREN.

📦 One day. One Experience.

AUREN is an offline-first app that gives you one real-world Experience at a time.

The idea is simple:

📱 Most apps ask for more screen time.
🌍 AUREN tries to give some of it back.

How it works:

📦 Open AUREN
🎲 Reveal one Experience
🚶 Go do it in real life
↩️ Return
📝 Reflect
🗂️ Archive it

After every Experience, AUREN asks:

1. Would you have done this without AUREN?
2. Was it worth your time?

The best result:

❌ NO
✅ YES

That means AUREN helped you do something you probably would not have done by default, and it was worth your time.

Version 1 includes:

📚 160 curated real-life Experiences
🤖 Android support
🪟 Windows support
🔒 Offline-first architecture
🧠 No personality scores
☁️ Encrypted backup export/import

What AUREN avoids:

🚫 No feeds
🚫 No streaks
🚫 No XP
🚫 No leaderboards
🚫 No account required
🚫 No ads
🚫 No analytics

Some Experiences ask you to:

👀 Observe something
🛠️ Repair something
✍️ Write something
🎧 Listen carefully
🧭 Navigate differently
🤝 Help someone
🏛️ Visit somewhere
🔎 Notice something you usually pass by

You do not have to succeed.
You only have to experience it.

Failure counts. You were there.

Built with Flutter, Dart, SQLite, and an offline-first architecture.

Download / GitHub:
https://github.com/VivekKumar0987/AUREN

For Android:
Download AUREN-Android.apk and install it from the official GitHub repository.

For Windows:
Download AUREN-Windows-Portable.zip, extract it, and open AUREN.exe.

I would love feedback from builders, designers, Flutter developers, privacy-first software people, and anyone interested in tools that encourage real-world action.

Would you use an app like this?

#Flutter #Dart #AndroidDevelopment #WindowsApp #OfflineFirst #PrivacyFirst #OpenSource #ProductDesign #UXDesign #SoftwareEngineering #BuildInPublic
```
